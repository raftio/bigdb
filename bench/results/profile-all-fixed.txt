`all()` and `matching(>=0)` return the same set by different means - one reads the stored exists row, the other computes it from 20 bit planes.
`group/all()` and `group/pred` are the same call over those two bitmaps, with the bitmap built outside the timed region.
If `all()` dominates, the report's suspect is confirmed. If the two `group/` columns differ instead, it is not.
